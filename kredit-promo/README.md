# Промо-ролик «Кредиттік жүйе»

Remotion 4 + three.js (`@remotion/three`, `@react-three/fiber` 8), 1920×1080, 30 fps, 900 кадров.

```bash
npm i
npm run studio        # превью
npm run check         # tsc + проверка раскладки (монеты/подписи в кадре, без пересечений)
npm run render        # out/kredit-promo.mp4 (--gl=angle, нужна GPU)
npm run render:sw     # то же на SwiftShader (--gl=swangle) — для машин/контейнеров без GPU
```

Если Remotion не может скачать Chrome Headless Shell, укажите готовый бинарник:
`REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render`.

## Структура

- `src/world/formations.ts` — чистые функции: таймлайн, 8 формаций (F0–F7), морфинг `poseAt(i, f)`, проекция 3D → экран.
- `src/world/layout.ts` — экранные точки подписей поверх проекции.
- `src/world/CoinWorld.tsx` — r3f-сцена: свет, туман, 181 монета (только `useCurrentFrame`).
- `src/scenes/*` — HTML-оверлеи сцен S1–S7, `src/Promo.tsx` — сборка.
- `src/FontTest.tsx` — композиция `FontTest` для проверки казахских букв.
- `scripts/check-layout.ts` — проверка раскладки (размеры текста меряются в Chromium с теми же шрифтами).

## Отступления от ТЗ

- **Шрифт заголовков — Montserrat вместо Unbounded.** В Unbounded на Google Fonts нет ә ғ қ ң ө ұ ү һ
  (`cyrillic-ext` содержит всего 6 глифов), они рендерились бы чужим шрифтом.
- **F1:** кольцо из 30 монет на z = −3 (иначе нижние монеты задевают строку «30 академиялық сағат»);
  «стена» 15×10 — на z = −18, центр y = 3.1 (на z = −14 она стояла под текстом нижней трети).
- **F4:** стопки на z = −3 (на z = 0 стопка из 120 монет с подписями не помещается по высоте).
- **F6:** центр орбит (0, −0.6, −4) (на z = 0 нижний конец вертикальной орбиты уходит под нижнюю подпись).
- **F7:** кольца на z = 1 вместо −5 (на −5 внутреннее кольцо режет строки 84 px), кольца обрамляют текст и частично уходят за кадр.
- Повороты монет — Euler в порядке `YXZ`, чтобы `rotation.y` поворачивал монету вокруг вертикали экрана
  (в порядке XYZ поворот по y у монеты, развёрнутой к камере, был бы вращением вокруг собственной оси — невидим).
- В F3 монеты потока плавно сжимаются у концов кривой, чтобы не «прыгать» при переходе u: 1 → 0.
